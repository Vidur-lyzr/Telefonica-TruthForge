# 04 · Ask / Chat  (Category A · CROSS)
### The core, naked — one question, one cited answer, one place

> Inherits FOUNDATION + File 01. The hero of the demo and the purest expression of the thesis. This is HOME app 1: the **cross-cutting** assistant that talks to *all* the SSoT data the user is allowed to see — distinct from the module-scoped chat windows in KPIs and Planning (which see only their module).

---

## 1. The job

A Comms leader asks a question in natural language and gets an answer they can **walk into a committee and defend** — source, version, owner, validity, confidence — or an honest "I don't have evidence." One question, one place, no hunting through SharePoint.

Short answer, rich evidence — the inverse of a chatty assistant. Figures in mono. The **Strategic-layer axis pill** sits at the answer's edge (always tell the user which axis).

---

## 3. Answer anatomy

1. **Direct answer** — one or two sentences, no preamble.
2. **Evidence Chip(s)** — inline on each figure/claim → tap opens the citation drawer with the **3-layer metadata**: deterministic (source·version·owner·validity·confidentiality), semantic (topic/entities), strategic (axis), plus relevance score and corroboration count.
3. **One line of context** — only if it adds defensibility.
4. **Actions** — `sources (n)` · `export to report` (one-off) · `save as insight` · `drill-in`.

No walls of text. If the honest answer is one number, it's one number — with its receipt.

---

## 4. Four-way retrieval (their words: "semantic + agentic + graph + keyword")

Per turn: resolve `user_scope` → the planner runs **hybrid retrieval across four modes** — *semantic* (Lyzr KB vector), *agentic* (the agent plans multi-step lookups), *graph* (Lyzr KG: entities, relationships, axes), *keyword* (exact acronyms/figures/names) — merges, and binds each claim to its citation. Numeric questions route to Text-to-SQL over the validated zone. The filter is applied **before** retrieval; the model never sees a chunk outside scope.

---

## 5. The hero behaviors (the demo script)

**① Defensible figure.** *"What revenue do we defend for Q1 2026?"* → €8,127M, full chip, "3 sources agree." Tap → the exact slide + IR ownership. *The whole pitch in one exchange.*

**② Honesty trap.** *"What's Vivo's position in Mexico?"* → *"Vivo operates in Brazil, not Mexico — and Telefónica has been exiting Spanish America (Chile sold 10 Feb 2026)."* No fabrication.

**③ Historic flag.** *"Revenue last quarter?"* → figure badged **historic**, with *"the Q1 2026 series (€8,127M) is the current one — want that?"*

**④ Permission block.** A Comms user without confidential access asks for **pre-publication Q1 figures** → *"There are relevant sources you don't have access to (Finance/IR · confidential-until-published). Request access from the owner."* The chunk never entered context — say so plainly.

**⑤ Conflict flag.** If an older messaging doc contradicts the newer Q1 release → *"The approved messaging says X; the Q1 release (14 May) says Y."* Offer to route to the Wiki for resolution.

---

## 6. Attachments in chat (confirmed capability)

The user can **attach a document into the conversation** — a speech draft, a results Excel, a third-party PDF — and the agent works it *against* SSoT knowledge: *"take this draft and complete/contrast it with our data."* The attachment enters as **working context only**; the user may optionally choose to **ingest it into the SSoT** (→ becomes governed, versioned E-data). Until then it never pollutes the corpus.

---

## 7. Memory & history (confirmed capability)

- **Context memory within a thread** — chained follow-ups keep the thread *and* filters ("and in Germany?", "expand point 2").
- **Persistent per-user history across sessions** — the user can **resume yesterday's task/conversation**. Backed by Lyzr Agent Memory; scoped per user; never leaks across users or permissions. Each resumed turn re-resolves permissions and re-cites — memory never grants access a fresh query wouldn't.

---

## 8. Actions from the chat (and the boundaries)

- **Export to report** — one-off only, hands to the **Generate** engine (Case 4) for on-brand `.docx/.pptx/.pdf` → Canvas. **Scheduled/recurring automation is NOT set up from chat** — that lives only in Generate's scheduled mode. Keep this boundary clean.
- **Save as insight** — into the SSoT with 3-layer tags → versioned E-data.
- **Drill-in** — open any cited source: document preview, jump to the Excel cell/table, view the version.
- **Suggested next steps** — quiet chips drawn from what's actually possible with the retrieved knowledge, not generic prompts.

---

## 9. States & guardrails

- **No evidence** — the honest line with dignity, plus (if useful) the closest adjacent/historic datum.
- **Low confidence** — muted score + "single source, expired — check before quoting." Never hide uncertainty.
- **Conflict** — surface both chips + "these disagree" → Wiki resolution path (the compounding loop starting in chat).
- **Empty/first run** — the ask bar + three example questions that *are* the demo beats.
- **Audit** — every query logged (who asked what, which sources used) for the audit trail.

---

## 10. Why this page wins

In sixty seconds an evaluator watches the product be *right and provable*, *honest when it doesn't know*, *aware of what's stale*, *incapable of leaking what you can't see*, and *able to work on a document you hand it* — with memory to resume tomorrow. That's the whole RFP thesis, delivered as a conversation. Ask is where Copilot loses.

# IconButton

**What & when:** Circular icon-only control for toolbars, cards and nav (menu, close, search). Always pass `label`.

```jsx
<IconButton label="Search" variant="ghost"><IconSearch/></IconButton>
<IconButton label="Menu" variant="outline" size="lg"><IconMenu/></IconButton>
```

**Variants:** `ghost` (default), `solid` (blue), `outline`. **Sizes:** `sm` 32 · `md` 40 · `lg` 48.

# Select · Checkbox · Radio · Switch

**Select** — native dropdown, brand outline + chevron.
```jsx
<Select label="Country" placeholder="Choose…"><option>Spain</option><option>Brazil</option></Select>
```

**Checkbox** — square, white tick on blue.
```jsx
<Checkbox label="I accept the terms" defaultChecked />
```

**Radio** — round; group by shared `name`.
```jsx
<Radio name="plan" label="Contract" defaultChecked /><Radio name="plan" label="Prepay" />
```

**Switch** — on/off toggle, blue when on.
```jsx
<Switch label="Auto-renew" defaultChecked />
```
